# 오늘 나가?

제주 날씨·물때 보고 나갈지 정하고, 다녀온 곳을 지도에 남기는 오프라인 웹앱.
폰에 설치해서 쓴다. 계정도 서버도 없고 기록은 폰 안에만 있다.

**주소**: https://jeju-eco.github.io/oneul/

## 한 화면에 뭐가 있나

**위** — 오늘 나가기 좋은지 점수 하나로. 그 아래 물때·다음 만조/간조·일몰·달.
**가운데** — 제주 전도. 다녀온 곳(청록), 안 간 오름(회색), 먹은 곳(주황).
**아래** — `＋다녀옴` 한 번이면 기록 끝.

## 기능

- **나들이 점수** — 시간별 비·바람·구름·기온으로 0~5점. 오후에 좋아지면 그 시각을 알려준다.
- **물때** — 8물때식(제주). 음력으로 계산하고 조위 예보에서 만조·저조 시각을 분 단위로 뽑는다.
- **오름 68개** — 탐방 가능 오름. 안 간 곳만 가까운 순으로 추천하고, 다녀오면 지도 색이 바뀐다.
- **먹은 곳** — 이름만 적으면 그때 날씨·물때가 같이 박힌다.
- **검색** — 내 기록이 먼저, 없으면 안 간 오름. 초성 됨(`ㄱㅅ` → 고기국수집).
- **되돌리기** — 잘못 지워도 6초 안에 살릴 수 있다.
- **오프라인** — 한 번 본 지도는 저장해두고 통신이 끊겨도 보인다. 날씨도 마지막 값을 쓴다.
- **내보내기** — 엑셀에서 바로 열리는 CSV.

## 폰에 설치

1. 폰 브라우저로 https://jeju-eco.github.io/oneul/ 접속
2. 아이폰: 공유 → **홈 화면에 추가** / 안드로이드: 메뉴 → **홈 화면에 추가**
3. 홈 화면 아이콘으로 실행 — 주소창 없는 전체화면으로 뜬다

> 첫 실행은 인터넷이 연결된 상태에서, 지도를 한 번 훑어두면 그 범위가 폰에 저장된다.
> 위치 권한을 허용해야 가까운 오름 추천과 먹은 곳 지도 표시가 된다.

기록은 저장 버튼이 없다. 누르는 즉시 저장된다.

## 데이터 출처

| 무엇 | 어디서 | 키 |
|---|---|---|
| 날씨·일출몰 | [Open-Meteo](https://open-meteo.com/) | 불필요 |
| 조위·파고 | [Open-Meteo Marine](https://open-meteo.com/en/docs/marine-weather-api) | 불필요 |
| 지도 | [OpenStreetMap](https://www.openstreetmap.org/) | 불필요 |
| 오름 68개 | 제주특별자치도 이용가능 오름현황 (공공데이터, 2021-05-10 기준) | — |

**오름 목록의 한계**: 제주 오름은 368개지만, 위경도가 공개된 것은 탐방 가능한 68개뿐이다.
나머지는 좌표를 구하지 못해 넣지 않았다. 좌표를 구하면 `data/oreum.json`만 갈아끼우면 된다.
`갑마장길`·`한남리머체왓숲길`은 둘레길이라 원본 표고가 0이고, 표고를 표시하지 않는다.

**달 밝기**는 음력 기준 근사값이다(정밀 천문 계산이 아니다).

## 검증

```bash
npm test          # 167개 — 로직 84 + 화면 83
npm run mutate    # 33개 버그를 심어 테스트가 잡는지 확인 (33/33 검출)
```

`npm run mutate`가 전체 검증이다. 테스트가 '그냥 통과만 하는' 가짜인지 잡아낸다.
일부러 버그 버전으로 되돌려 실패하는 걸 확인해야 진짜다.

## 개발

```bash
npm run serve     # http://localhost:8778
npm run icons     # 아이콘 다시 만들기 (Pillow 필요)
```

| 파일 | 뭘 하나 |
|---|---|
| `core.js` | 순수 로직 — 물때, 조위 극값, 점수, 검색, 거리. DOM을 모른다. |
| `app.js` | 화면·저장·네트워크·지도. |
| `data/oreum.json` | 오름 68개. |
| `sw.js` | 앱 껍데기 캐시. 날씨와 지도 타일은 건드리지 않는다. |

## 만든 이유

제주 살면서 "오늘 나갈까"를 앱 네 개 열어 판단하고 있었다.
날씨 앱, 물때 앱, 지도, 그리고 어디 갔었는지 기억.
그걸 한 화면으로 합쳤다.
